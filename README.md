# AutoControl 2.0

Pacote de atualização da PWA AutoControl.

**Base atual preservada:** `autocontrol:v1` no localStorage. Não substitua `legacy-desktop/`.

## Como aplicar

1. Faça uma cópia do repositório atual.
2. Substitua `index.html`, `css/styles.css` e os arquivos dentro de `js/` pelos deste pacote.
3. Mantenha a pasta `icons/` e `legacy-desktop/` do repositório atual.
4. Publique novamente no GitHub Pages.
5. Se a interface antiga aparecer, faça Ctrl+F5 e limpe o cache do Service Worker.
